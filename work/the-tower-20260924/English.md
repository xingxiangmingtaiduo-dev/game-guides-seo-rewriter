# The Tower AFK Guide: Coins, Gems, Research, and UgPhone

The Tower rewards a simple loop: fight, collect coins, improve the account, and return to a stronger wave. Progress slows when currency is left unspent or a long session stops early. This **The Tower AFK Guide** explains where coins and gems come from, what each currency is for, and how UgPhone can keep a permitted session running without tying up your phone. Check one short run first, then extend it.

## What Is The Tower?

The Tower is a wave-based progression game. Combat is the main source of coins, and higher levels usually provide a faster multiplier. Missions are another reliable source, so collect them whenever an objective is complete.

<!-- SOURCE_IMAGE:2 -->

Coins have two important uses. Spend them on attribute upgrades when the next wave is becoming difficult, then use the remaining budget for research. A stronger build improves combat income, while research supports longer-term account growth.

## How to Get and Spend Gems

Gems can be earned by watching optional advertisements. The main menu, battle screen, and shop may each display an available reward, so check all three locations instead of waiting in one screen.

<!-- SOURCE_IMAGE:5 -->

During a battle, a gem reward can also appear. Tap it when it is visible to receive two gems. This small pickup is easy to miss during a busy wave, but it adds up over repeated runs.

<!-- SOURCE_IMAGE:6 -->

Paid gem purchases are another option, but they are not required for the basic progression loop. Save earned gems for card slots and cards first, because these upgrades can improve the account across many runs.

<!-- SOURCE_IMAGE:7 -->

Gems can also buy laboratory slots or speed up research. Use them where they remove a real bottleneck.

<!-- SOURCE_IMAGE:8 -->

## How UgPhone Helps The Tower AFK Farming

UgPhone is useful when The Tower can continue fighting but your phone should not stay awake. A cloud device keeps the game running while reducing physical heat, battery use, and screen time. It also supports multiple games and group controls.
